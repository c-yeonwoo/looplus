# 화면 시안 자산

2026-10-23 화면 설계를 위한 **정적 검토용 이미지**다. 앱 구현·네이티브 캡처·검증 결과가 아니다.
최신 이미지는 `routine-selection-v3.png`다. 대표 루틴 라이브러리와 승인된 NeoRound 제목 방향을 참고했다.
정식 폰트 파일로 렌더링하지 않았으며 이미지 속 글자는 실제 상용 서체의 견본이 아니다.

- `routine-selection-v3.png`: 대표 6개 고르기, 설정 확인, 생성 직후 오늘, 선택 경로인 전체 24개 목록.
- `routine-selection-v3-prompt.txt`: v0.3 이미지 생성에 사용한 전체 원문 프롬프트. PNG 메타데이터에도 포함.
- `core-flows-v1.png`: 첫 루틴, 오늘 목록, 복귀 초대, 주간 계획 변경 확인.
- `mockup-prompt.txt`: 위 이미지 생성에 사용한 전체 원문 프롬프트.
- `connected-tabs-v1.png`: 목표 상세, 기록 홈, 선택형 돈 관리 연결 화면.
- `companion-prompt.txt`: 목표·기록·선택형 도구 연결 화면의 원문 프롬프트.

생성 도구는 built-in imagegen이다. 첫 보드는 새 생성, 연결 화면 및 v0.3 보드는 첫 보드를 시각 참조로 사용한다.
v0.1 생성 폼은 v0.3으로 대체한다. v0.1의 나머지 화면은 이전 구조 참고로 보존한다.
시안의 데이터는 가상 예시다. 제목용 NeoRound 방향은 승인되었지만 개별 픽셀 배치와 실제 렌더링 검증은 별도다.
실제 동작과 문구의 기준은 `../../CORE_FLOWS_SCREEN_DESIGN.md`다.
목표 플랫폼은 iOS/Android지만 이 이미지는 iOS에 가까운 표현을 사용한 공통 구조 검토안이다.
Android 고유 컴포넌트·Back·IME·접근성 및 양 OS 다크 모드는 별도의 구현/검증 대상이다.
