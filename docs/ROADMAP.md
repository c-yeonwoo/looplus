## 지금 위치 (2026-09 기준)

✅ 재테크 엔진·민감도 밴드·목표 가드·지출·실천·동기화 기반
✅ **Loop OS v1 기반** — 계정 없는 첫 곡선 체험, 4개 숫자 간편 온보딩, 여러 큰 루프, 큰 루프에 연결된 작은 실행, 홈 진행 가시성, 지출 자동 반영 기본값

**제품 정의:** Loop+는 그래프를 한 번 보는 시뮬레이터가 아니라, 작은 실행을 반복해 여러 큰 자산·인생 루프를 하나씩 완성하는 플랫폼이다.

**운영 스위치 (배포 환경에서 설정 필요):** `NEXT_PUBLIC_POSTHOG_KEY` · `NEXT_PUBLIC_LEAD_URL`.
**아직 없음:** 실제 리드 목적지 검증 · AI 코치 런타임 · 마이데이터 · 푸시/메일 리마인더.

## v1.0 — Loop OS GA: "첫 곡선에서 첫 실행까지" (획득 + 신뢰)
> 목적: 사용자가 90초 안에 자신의 첫 큰 루프와 곡선을 보고, 가입 전에 가치를 확인하게 한다.

1. **운영 계측 실연결** — PostHog에서 `guest_started → onboarding_completed → engine_result_viewed → goal_loop_created → action_added → action_completed` 퍼널을 운영한다.
2. **온보딩 검증** — 4개 숫자 간편 입력, 계정 없는 체험, 진단 우선 순서의 완료율/아하 도달률을 비교한다.
3. **신뢰 최종 감수** — 수익률 가정·민감도·지출 자동 반영·로컬 체험의 저장 범위를 명확히 고지한다.
4. **리드 CTA 판단** — 실제 목적지가 준비되기 전에는 "곧 연결" CTA를 노출하지 않는다. 준비되면 파트너·목적·광고성 여부를 명확히 표시한다.

**출구 지표:** 첫 결과 도달 시간, 온보딩 완료율, 큰 루프 생성율, 첫 작은 루프 생성율의 2주 baseline 확보.

## v1.1 — 실행·모니터링 루프
> 목적: 그래프를 본 사람이 매주 실제로 한 칸 전진하게 한다.

- **단계 → 작은 루프 자동 제안** — 다음 한 걸음을 실행 항목으로 직접 등록하고, 해당 큰 루프에 연결한다.
- **주간/월간 점검** — 순자산·저축률·지출 변화가 어느 큰 루프를 얼마나 밀었는지 설명한다.
- **지출 단일 기준 강화** — 고정·변동 지출을 기록하면 진단·저축률·엔진 전망을 즉시 갱신하고, 변경 전후를 보여 준다.
- **리마인더 옵트인** — 사용자가 고른 주간 점검일에만 이메일/푸시를 보낸다.

**출구 지표:** 첫 작은 루프 완료율, 주간 점검율, D7 재방문율.

## v1.5 — 여러 큰 루프의 로드맵
> 목적: 하나의 FIRE 목표가 아니라, 비상금·부채·현금흐름·자산 자유를 순서대로 완성하게 한다.

- 큰 루프 간 의존성/권장 순서(예: 비상금 → 저축률 → 투자 루프)를 사용자에게 강요하지 않고 제안한다.
- 큰 루프별 진행 이력, 완성 축하, 다음 루프 추천을 제공한다.
- 모바일 엔진 UX를 실제 사용성 테스트 결과로 다듬는다.

## v2 — AI 코치 + 자동연동
> 목적: 차별화·프리미엄·마찰 제거.

- **AI 재무 코치** — 배분 비평·설명·"왜?" (가드레일: 배분 구조·개념까지, 개별 종목·매물 금지). 프리미엄 웨지.
- **NL 진단 입력** — 자연어 → 스냅샷 자동 채움.
- **오픈뱅킹/마이데이터 연동** — 자동 진단(단계·달성률·ETA 자동 추산), 데이터 자동 신선화.

## v2+ — 확장
